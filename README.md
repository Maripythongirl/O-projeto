# 🌦️ Clima Seguro

## Esse é o tipo do meu projeto:
> Aplicativo web desenvolvido em Python para apresentar previsões do tempo, emitir alertas sobre possíveis desastres climáticos e incentivar projetos voluntários para ajudar a cidade na prevenção desses acontecimentos.

## 🎯 Objetivos
* Informar a população sobre a previsão do tempo.
* Emitir alertas sobre possíveis desastres climáticos.
* Incentivar projetos voluntários para prevenir desastres e ajudar a comunidade.

## As bibliotecas que vou usar:
- **JSON:** leitura, organização e armazenamento de dados recebidos de APIs.
- **Folium:** criação de mapas interativos para mostrar regiões de risco.
- **GeoJSON:** representação de informações geográficas, como coordenadas e áreas afetadas.
- **Flask:** desenvolvimento do site e organização das páginas.
- **Requests:** comunicação com APIs para obter informações meteorológicas e alertas.

## Referências úteis:
- [AlertaBlu](https://www.blumenau.sc.gov.br/) — referência para monitoramento climático e alertas locais.
- [Google Flood Hub](https://sites.research.google/floods/) — inspiração para mapas de previsão de enchentes.
- [Defesa Civil](https://www.gov.br/mdr/pt-br/assuntos/protecao-e-defesa-civil) — informações sobre prevenção e segurança em desastres.
- [INMET](https://alertas2.inmet.gov.br/) — consulta de avisos meteorológicos no Brasil.
- [Google Weather API](https://developers.google.com/maps/documentation/weather?hl=pt-BR) — documentação sobre previsão e alertas meteorológicos.

## Os artigos de orientação que me ajudarão durante o desenvolvimento:
- Tutorial de Flask: ensina a criar aplicações web utilizando Python, organizar páginas e trabalhar com funcionalidades do site. [Acessar tutorial](https://flask.palletsprojects.com/en/stable/tutorial/)
- Guia de Requests: explica como realizar requisições HTTP para acessar APIs e receber informações externas. [Acessar guia](https://requests.readthedocs.io/projects/pt/pt-br/latest/user/quickstart.html)
- Guia de Folium: apresenta como criar mapas interativos, adicionar marcadores e destacar regiões geográficas. [Acessar guia](https://python-visualization.github.io/folium/v0.19.1/user_guide.html)
- Documentação de GeoJSON: explica como representar coordenadas, pontos, linhas e áreas geográficas utilizando dados estruturados. [Acessar documentação](https://www.rfc-editor.org/rfc/rfc7946)
- Documentação de JSON: ensina a ler, escrever e organizar dados no formato JSON utilizando Python. [Acessar documentação](https://docs.python.org/pt-br/3/library/json.html)
- Tutorial de alertas meteorológicos: explica como consultar alertas climáticos, identificar áreas afetadas e obter informações sobre a gravidade dos eventos. [Acessar tutorial](https://developers.google.com/maps/documentation/weather/weather-alerts?hl=pt-BR)

##🌱 Impacto social

O projeto busca unir tecnologia e participação comunitária para ajudar na prevenção de desastres climáticos, emitir alertas importantes, promover a segurança da população e incentivar a solidariedade.
